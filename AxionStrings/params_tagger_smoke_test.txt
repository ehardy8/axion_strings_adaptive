# Smoke test for the real (plaquette-based) string tagger, milestone-2
# Phase 1 (2026-09-19): checks refinement actually tracks a genuinely
# sparse string network (fourier_relaxed, not the raw noisy IC a first
# attempt at this test used -- that gave ~100% tagged, which turned out to
# be the deliberately-noisy unrelaxed field spuriously "piercing" nearly
# every plaquette, not a tagger bug: exactly the effect pre-evolution
# exists to remove, per this project's own established understanding).
#
# Box plan by hand (N=128 effective, N1=N2=1, a_inv=2, c=0 physical,
# max_level=2): tau_f=11.31, L_tilde=11.31, N_base=32, dx_base=0.3536,
# level thresholds at log(m_r/H)=2.080 (level 1), 3.466 (level 2).
# log_mr_over_h_i=1.0 is comfortably below both -- refinement should
# appear "for free" once the string network forms, well before either
# threshold is nominally required by resolution alone.
#
# pre_evolution.k_max_over_mr = 64, not 16 (2026-09-25, with the user,
# investigating "radial mode oscillations obscuring the physics"): at 16,
# this config's own freshly-generated Fourier IC already has xi below
# xi_target=1.0 (confirmed directly: xi~0.20 at N=128), so the xi-
# monitoring loop used to exit on its very first check -- pre-evolution
# was a silent no-op here too, which quietly undermines this file's own
# stated purpose above ("exactly the effect pre-evolution exists to
# remove"): the sparse network this test saw was actually just k_max=16's
# own low fresh-IC string density, not evidence relaxation had done
# anything. 64 matches the k_max_over_mr already used in the real
# production configs, giving a fresh xi far above target (~40x, densely
# tangled -- the regime this test is specifically meant to guard against
# spuriously over-tagging) so relaxation is now genuinely exercised down
# to the same xi_target=1.0 sparse network this test always intended to
# check against. Confirmed level 1 still activates and the tagged fraction
# stays well below 100%. See docs/STATUS.md's "known issues" for the
# fuller radial-mode investigation this came out of.
